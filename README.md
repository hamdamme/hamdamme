## Selected work

### Digital Grader

A Java submission and review platform with cohort management, assignment rubrics, queued execution, and security feedback. Built with Spring Boot, PostgreSQL, RabbitMQ, React, and TypeScript. Submitted projects run in gVisor containers. Grade integrity for adversarial submissions remains an open engineering task.

[Source and setup](https://github.com/hamdamme/digital-grader) · [Demo](https://grader.hamdam.me)

### Routing Topology

An interactive network editor for comparing Dijkstra, Bellman–Ford, and Distance Vector. Includes routing tables, algorithm playback, failure scenarios, and topology exports. The Java engine is checked against an independent reference implementation.

[Source and tests](https://github.com/hamdamme/routing-topology) · [Demo](https://network-routing-simulator.onrender.com/)

### CASF

A Python framework for cryptographically verifiable audit records with conditional rollback detection using independently retained witness state. Includes an independent verifier, conformance vectors, adversarial tests, and documented evaluation limits.

[Source, evaluation, and limitations](https://github.com/hamdamme/casf)
